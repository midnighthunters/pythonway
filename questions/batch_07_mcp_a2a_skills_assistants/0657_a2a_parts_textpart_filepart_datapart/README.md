# Q0657 · A2A Parts: TextPart, FilePart, DataPart

## Question

Explain the role of Parts in A2A task inputs and outputs. Write Python classes modeling TextPart, FilePart, and DataPart with validation.

## Answer

In A2A, message payloads are composed of heterogeneous Parts:
1. `TextPart`: Natural language instructions, reasoning steps, or conversational summaries.
2. `DataPart`: Structured JSON data conforming to a domain schema (e.g. calculation results, table rows).
3. `FilePart`: References or base64 streams of documents, reports, or charts generated by the agent.

```python
from typing import Any, Dict, Optional
from pydantic import BaseModel, Field


class TextPart(BaseModel):
    type: str = Field(default="text", frozen=True)
    text: str


class DataPart(BaseModel):
    type: str = Field(default="data", frozen=True)
    data: Dict[str, Any]


class FilePart(BaseModel):
    type: str = Field(default="file", frozen=True)
    uri: str
    mimeType: str
    filename: Optional[str] = None


p1 = TextPart(text="Valuation calculated.")
p2 = DataPart(data={"npv": 1250000.0, "currency": "USD"})
p3 = FilePart(uri="s3://reports/2026/val_sheet.xlsx", mimeType="application/vnd.ms-excel", filename="val_sheet.xlsx")

assert p1.type == "text"
assert p2.data["npv"] == 1250000.0
assert p3.mimeType == "application/vnd.ms-excel"
```
