# B0059 · Learned a new technology quickly

| Section | Topic | Difficulty |
|---|---|---|
| Behavioural, Role & JPMorganChase | Behavioral - learning | Easy |

## Question

Tell me about a time you had to learn a new technology quickly.

## Answer

- Situation: you needed to build an MCP server and connect it to a LangGraph agent within two weeks.
- Action: read the spec and SDK docs, built a toy end-to-end in a day, listed production concerns (auth, timeouts, error handling), asked experts targeted questions, wrote tests, and documented what you learned.
- Result: shipped on time, became the team's reference point, and ran a knowledge-sharing session.

Describe your learning method; "I'm a fast learner" on its own is not evidence.

## Likely follow-ups

- What was hardest to learn?
- How do you avoid shallow understanding when learning fast?
