# B0030 · Questions to ask the interviewer

| Section | Topic | Difficulty |
|---|---|---|
| Behavioural, Role & JPMorganChase | Closing | Easy |

## Question

Do you have any questions for us?

## Answer

Always ask two or three thoughtful questions tailored to the interviewer:

- Technology: "What does the agent runtime behind LLM Suite look like today, and where is the biggest scaling pain?" "Are MCP and A2A used only internally, or also to integrate vendor agents?"
- Practice: "How are model and prompt changes evaluated before release?" "What does on-call look like for this team?"
- Success: "What would a great first six months look like in this role?"
- Collaboration: "How are design decisions made across the LLM Suite teams?"
- Growth: "How do engineers here progress towards Lead level?"

Avoid questions the JD already answers, and keep compensation for the recruiter.

## Likely follow-ups

- What else would you like to know about the team?
