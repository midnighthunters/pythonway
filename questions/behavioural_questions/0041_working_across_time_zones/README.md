# B0041 · Working across time zones

| Section | Topic | Difficulty |
|---|---|---|
| Behavioural, Role & JPMorganChase | Behavioral - collaboration | Easy |

## Question

Tell me about working in a globally distributed team.

## Answer

- Practices: written-first communication (design docs, clear tickets, decision logs), agreed overlap hours, rotating meeting times fairly, async stand-ups, recorded demos, explicit handoff notes.
- Example: working with engineers in New York and Bengaluru on a shared service, you introduced a handoff template and contract tests so each location could progress independently, and cycle time dropped.
- Cultural awareness: communication styles differ, so check understanding explicitly.

## Likely follow-ups

- How do you handle an urgent issue when the owner is asleep?
- How do you avoid decisions being made without remote teammates?
