## Question

Which agentic use cases would you prioritise for Finance, Treasury, Risk, Compliance, Legal and HR?

## Answer

Prioritise by value × feasibility × risk:

- Finance: drafting variance commentary, triaging reconciliation exceptions, month-end close checklists.
- Treasury: summarising liquidity reports, explaining cash-forecast movements.
- Risk: summarising risk reports, gathering control-testing evidence, policy Q&A with citations.
- Compliance: assisting alert triage (a human decides), summarising regulatory change and mapping it to policies.
- Legal: clause extraction and comparison, first drafts from approved templates reviewed by lawyers.
- HR: policy Q&A, job-description drafting, onboarding assistants.

Principles: start read-only or draft-only with a human in the loop, cite sources, use entitlement-aware retrieval, measure against a baseline, and only then add actions behind approvals.

## Likely follow-ups

- Which use case would you avoid initially, and why?
- How would you evaluate the compliance use case?
