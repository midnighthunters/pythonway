# B0050 · Working with different working styles

| Section | Topic | Difficulty |
|---|---|---|
| Behavioural, Role & JPMorganChase | Behavioral - collaboration | Easy |

## Question

How do you work with someone whose working style is very different from yours?

## Answer

- Name the differences (planner vs explorer, written vs verbal, early vs last-minute).
- Talk about preferences explicitly and agree norms: update cadence, where decisions are recorded, review expectations.
- Use complementary strengths: one explores options, the other drives to closure.
- Assume positive intent and focus on outcomes.

Example: a data scientist who preferred notebooks. You agreed a handoff contract (tested, packaged functions with typed inputs), which made productionising their work smooth.

## Likely follow-ups

- How would you describe your own working style?
- Tell me about a style clash that didn't resolve.
