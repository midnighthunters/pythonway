# B0035 · Project that needed cross-team coordination

| Section | Topic | Difficulty |
|---|---|---|
| Behavioural, Role & JPMorganChase | Behavioral - collaboration | Medium |

## Question

Describe a project that required coordination across several teams.

## Answer

- Situation: e.g. integrating an agent with the identity and entitlements team, a document platform, the security review function and the UI team.
- Action: mapped dependencies and owners; wrote a short integration spec (APIs, SLAs, dates); ran a weekly sync and a shared channel; tracked risks; agreed interface contracts early and used mocks so teams could work in parallel; escalated a blocked dependency with a clear, specific ask.
- Result: delivered in X weeks, contract tests prevented integration breakages, and the pattern was reused by other teams.

Emphasise the communication artefacts and how you managed risk proactively.

## Likely follow-ups

- How did you handle a team that deprioritised your dependency?
- What would you do differently next time?
