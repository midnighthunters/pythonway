# B0039 · How you contribute in design discussions

| Section | Topic | Difficulty |

## Question

How do you contribute to design discussions when working with more senior engineers?

## Answer

- Prepare: read the document beforehand and come with questions and data.
- Clarify requirements and non-functional needs (latency, SLOs, security, cost) before jumping to solutions.
- Probe failure modes: "What happens when the model endpoint times out?" "How do retries interact with tool side effects?"
- Offer alternatives with trade-offs rather than bare objections.
- Be concise, respect the timebox, and capture decisions and open questions (for example in an ADR).
- Commit once decided; return with evidence if new data appears.
- Learn deliberately: ask why senior engineers prefer certain patterns.

## Likely follow-ups
