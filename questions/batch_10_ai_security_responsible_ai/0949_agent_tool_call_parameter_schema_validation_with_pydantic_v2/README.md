# Q0949 · Agent tool call parameter schema validation with Pydantic v2

## Question

Write Python code using Pydantic v2 to strictly validate tool arguments generated by an LLM function calling pipeline, rejecting type-mismatches and parameter injection.

## Answer

LLMs often hallucinate tool arguments (e.g. passing strings for integer IDs, negative dollar amounts, or extraneous injected fields). Validating arguments against strict Pydantic v2 models before invoking the Python tool function prevents runtime exceptions.

```python
from pydantic import BaseModel, Field, ValidationError


class TransferFundsArgs(BaseModel):
    account_id: str = Field(min_length=8, max_length=12, pattern=r"^[0-9]+$")
    amount_usd: float = Field(gt=0.0, le=100_000.0)
    currency: str = Field(default="USD", pattern=r"^[A-Z]{3}$")


def execute_transfer_tool(raw_args: dict) -> dict:
    try:
        validated = TransferFundsArgs(**raw_args)
        return {"status": "SUCCESS", "amount": validated.amount_usd}
    except ValidationError as e:
        return {"status": "VALIDATION_FAILED", "errors": e.errors()}


# Valid arguments
good_args = {"account_id": "1234567890", "amount_usd": 450.0}
res_good = execute_transfer_tool(good_args)
assert res_good["status"] == "SUCCESS"

# Invalid arguments: negative amount and non-numeric account ID
bad_args = {"account_id": "INVALID-ID", "amount_usd": -50.0}
res_bad = execute_transfer_tool(bad_args)
assert res_bad["status"] == "VALIDATION_FAILED"
assert len(res_bad["errors"]) >= 1
```
