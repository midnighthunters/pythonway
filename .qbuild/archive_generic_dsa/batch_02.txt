@@ Two Sum II - Input Array Is Sorted | Medium | Two pointers
Q: `numbers` is sorted in non-decreasing order. Return the 1-based indices of the two numbers that add up to `target`, using O(1) extra space.

Example: `[2,7,11,15], 9` → `[1,2]`
A:
Seen in: JPMorgan-tagged list.

Approach: start one pointer at each end. If the sum is too small, move the left pointer right; if too large, move the right pointer left. Each step discards one element that can't be part of any answer.

```python
def two_sum_sorted(numbers: list[int], target: int) -> list[int]:
    i, j = 0, len(numbers) - 1
    while i < j:
        s = numbers[i] + numbers[j]
        if s == target:
            return [i + 1, j + 1]
        if s < target:
            i += 1
        else:
            j -= 1
    return []


assert two_sum_sorted([2, 7, 11, 15], 9) == [1, 2]
assert two_sum_sorted([2, 3, 4], 6) == [1, 3]
assert two_sum_sorted([-1, 0], -1) == [1, 2]
assert two_sum_sorted([1, 2], 10) == []
```

Complexity: O(n) time, O(1) space.
F:
- Prove the pointer moves never skip the answer.
- Count all pairs with sum ≤ target.

@@ 3Sum | Medium | Two pointers
Q: Return all unique triplets `[a, b, c]` from `nums` with `a + b + c == 0`.

Example: `[-1,0,1,2,-1,-4]` → `[[-1,-1,2],[-1,0,1]]`
A:
Approach: sort. Fix `nums[i]` and run two pointers on the rest. Skip duplicate values for `i`, and skip duplicate values for `lo` after a match.

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    a = sorted(nums)
    out: list[list[int]] = []
    for i in range(len(a) - 2):
        if a[i] > 0:
            break
        if i > 0 and a[i] == a[i - 1]:
            continue
        lo, hi = i + 1, len(a) - 1
        while lo < hi:
            s = a[i] + a[lo] + a[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                out.append([a[i], a[lo], a[hi]])
                lo, hi = lo + 1, hi - 1
                while lo < hi and a[lo] == a[lo - 1]:
                    lo += 1
    return out


assert three_sum([-1, 0, 1, 2, -1, -4]) == [[-1, -1, 2], [-1, 0, 1]]
assert three_sum([0, 1, 1]) == []
assert three_sum([0, 0, 0, 0]) == [[0, 0, 0]]
```

Complexity: O(n²) time, and O(1) extra space besides the sort and the output.
F:
- Why is sorting needed for deduplication?
- 3Sum Smaller: count the triplets with sum < target.

@@ 3Sum Closest | Medium | Two pointers
Q: Return the sum of the three integers in `nums` whose sum is closest to `target`.

Example: `[-1,2,1,-4], 1` → `2`
A:
Approach: the same sort-and-squeeze pattern as 3Sum, tracking the best sum seen. Return early on an exact match.

```python
def three_sum_closest(nums: list[int], target: int) -> int:
    a = sorted(nums)
    best = a[0] + a[1] + a[2]
    for i in range(len(a) - 2):
        lo, hi = i + 1, len(a) - 1
        while lo < hi:
            s = a[i] + a[lo] + a[hi]
            if abs(s - target) < abs(best - target):
                best = s
            if s < target:
                lo += 1
            elif s > target:
                hi -= 1
            else:
                return s
    return best


assert three_sum_closest([-1, 2, 1, -4], 1) == 2
assert three_sum_closest([0, 0, 0], 1) == 0
assert three_sum_closest([1, 1, 1, 0], 100) == 3
```

Complexity: O(n²).
F:
- What if ties must return the smaller sum?

@@ 4Sum | Medium | k-Sum recursion
Q: Return all unique quadruplets that sum to `target`.

Example: `[1,0,-1,0,-2,2], 0` → `[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`
A:
Approach: a generic k-sum. Recurse down to 2-sum, which uses two pointers, and deduplicate at every level. It is worth showing because it generalises cleanly.

```python
def four_sum(nums: list[int], target: int) -> list[list[int]]:
    a = sorted(nums)

    def k_sum(start: int, k: int, t: int) -> list[list[int]]:
        res: list[list[int]] = []
        if k == 2:
            lo, hi = start, len(a) - 1
            while lo < hi:
                s = a[lo] + a[hi]
                if s < t:
                    lo += 1
                elif s > t:
                    hi -= 1
                else:
                    res.append([a[lo], a[hi]])
                    lo, hi = lo + 1, hi - 1
                    while lo < hi and a[lo] == a[lo - 1]:
                        lo += 1
            return res
        for i in range(start, len(a) - k + 1):
            if i > start and a[i] == a[i - 1]:
                continue
            for sub in k_sum(i + 1, k - 1, t - a[i]):
                res.append([a[i], *sub])
        return res

    return k_sum(0, 4, target)


assert four_sum([1, 0, -1, 0, -2, 2], 0) == [[-2, -1, 1, 2], [-2, 0, 0, 2], [-1, 0, 0, 1]]
assert four_sum([2, 2, 2, 2, 2], 8) == [[2, 2, 2, 2]]
```

Complexity: O(n^(k-1)), which is O(n³) for 4Sum.
F:
- Add pruning with min/max bounds at each level.
- Count quadruplets across four arrays (4Sum II, a hash map in O(n²)).

@@ Trapping Rain Water | Hard | Two pointers
Q: Given an elevation map, compute how much rain water it traps.

Example: `[0,1,0,2,1,0,1,3,2,1,2,1]` → `6`
A:
Seen in: JPMorgan-tagged list.

Approach: the water over bar i is `min(max_left, max_right) - h[i]`. Use two pointers and always process the side with the smaller bar, because that side's max is the binding constraint.

```python
def trap(height: list[int]) -> int:
    i, j = 0, len(height) - 1
    left_max = right_max = water = 0
    while i < j:
        if height[i] < height[j]:
            left_max = max(left_max, height[i])
            water += left_max - height[i]
            i += 1
        else:
            right_max = max(right_max, height[j])
            water += right_max - height[j]
            j -= 1
    return water


assert trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]) == 6
assert trap([4, 2, 0, 3, 2, 5]) == 9
assert trap([]) == 0
assert trap([3]) == 0
```

Complexity: O(n) time, O(1) space. Alternatives: prefix/suffix max arrays in O(n) space, or a monotonic stack.
F:
- Explain the monotonic-stack version (it computes the water in horizontal layers).
- Trapping Rain Water II on a 2-D grid (a min-heap from the border).

@@ Sort Colors | Medium | Dutch national flag
Q: Sort an array of 0s, 1s and 2s in place in one pass.

Example: `[2,0,2,1,1,0]` → `[0,0,1,1,2,2]`
A:
Approach: three regions: `[0, lo)` holds 0s, `[lo, mid)` holds 1s, and `(hi, end]` holds 2s. Do not advance `mid` after swapping with `hi`, because the swapped-in value hasn't been examined yet.

```python
def sort_colors(nums: list[int]) -> None:
    lo = mid = 0
    hi = len(nums) - 1
    while mid <= hi:
        if nums[mid] == 0:
            nums[lo], nums[mid] = nums[mid], nums[lo]
            lo += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[hi] = nums[hi], nums[mid]
            hi -= 1


for case in ([2, 0, 2, 1, 1, 0], [2, 0, 1], [0], [1, 1], [2, 2, 0, 0, 1]):
    expected = sorted(case)
    sort_colors(case)
    assert case == expected
```

Complexity: O(n) time, O(1) space, one pass.
F:
- The same partitioning drives 3-way quicksort. Why does it help with many duplicates?
- Sort with k colours (counting sort, or repeated partitioning).

@@ Squares of a Sorted Array | Easy | Two pointers
Q: Given a sorted array (which may contain negatives), return the squares in sorted order in O(n).

Example: `[-4,-1,0,3,10]` → `[0,1,9,16,100]`
A:
Approach: the largest square is at one of the two ends. Fill the output from the back.

```python
def sorted_squares(nums: list[int]) -> list[int]:
    n = len(nums)
    out = [0] * n
    i, j = 0, n - 1
    for w in range(n - 1, -1, -1):
        if abs(nums[i]) > abs(nums[j]):
            out[w] = nums[i] * nums[i]
            i += 1
        else:
            out[w] = nums[j] * nums[j]
            j -= 1
    return out


assert sorted_squares([-4, -1, 0, 3, 10]) == [0, 1, 9, 16, 100]
assert sorted_squares([-7, -3, 2, 3, 11]) == [4, 9, 9, 49, 121]
assert sorted_squares([]) == []
```

Complexity: O(n) time, O(n) output space.
F:
- Apply any monotonic-then-reversed function (`ax² + bx + c`): Sort Transformed Array.

@@ Backspace String Compare | Easy | Two pointers
Q: `#` means backspace. Return whether `s` and `t` are equal after typing both. Aim for O(1) space.

Example: `"ab#c", "ad#c"` → `True`
A:
Approach: walk backwards and skip the characters erased by `#`. Generators keep it readable, and `zip_longest` detects a length mismatch.

```python
from itertools import zip_longest


def backspace_compare(s: str, t: str) -> bool:
    def typed(x: str):
        skip = 0
        for ch in reversed(x):
            if ch == "#":
                skip += 1
            elif skip:
                skip -= 1
            else:
                yield ch

    return all(a == b for a, b in zip_longest(typed(s), typed(t)))


assert backspace_compare("ab#c", "ad#c")
assert backspace_compare("ab##", "c#d#")
assert not backspace_compare("a#c", "b")
assert backspace_compare("a##c", "#a#c")
```

Complexity: O(n + m) time, O(1) space.
F:
- The simpler stack version, and when you'd prefer it.

@@ Partition Labels | Medium | Greedy

```python
def partition_labels(s: str) -> list[int]:
    last = {ch: i for i, ch in enumerate(s)}

            sizes.append(end - start + 1)
            start = i + 1
    return sizes
```

@@ Bag of Tokens | Medium | Greedy two pointers
Q: Playing token i face up costs `tokens[i]` power and gains 1 score. Playing it face down costs 1 score and gains `tokens[i]` power. Each token is used at most once. Return the maximum score.

Approach: sort. Buy score with the cheapest token. When you can't, sell 1 score for the most expensive token. Track the best score seen, because the final score might be lower.

```python
def bag_of_tokens_score(tokens: list[int], power: int) -> int:
    t = sorted(tokens)
    i, j, score, best = 0, len(t) - 1, 0, 0
    while i <= j:
        if power >= t[i]:
            power -= t[i]
            i += 1
            score += 1
            best = max(best, score)
        elif score > 0:
            power += t[j]
            j -= 1
            score -= 1
        else:
            break
    return best


assert bag_of_tokens_score([100], 50) == 0
assert bag_of_tokens_score([200, 100], 150) == 1
assert bag_of_tokens_score([100, 200, 300, 400], 200) == 2
```

Complexity: O(n log n).

- Why track `best` rather than returning the final `score`?

@@ Longest Mountain in Array | Medium | Two pointers
Q: A mountain strictly increases and then strictly decreases, and has length at least 3. Return the length of the longest mountain subarray.

```python
def longest_mountain(arr: list[int]) -> int:
    n, best, i = len(arr), 0, 1
    while i < n:
        if arr[i] <= arr[i - 1]:
            i += 1
            continue
        start = i - 1
        while i < n and arr[i] > arr[i - 1]:
            i += 1
        if i < n and arr[i] < arr[i - 1]:
            while i < n and arr[i] < arr[i - 1]:
                i += 1
            best = max(best, i - start)
    return best
```

@@ Longest Substring Without Repeating Characters | Medium | Sliding window

```python
def length_of_longest_substring(s: str) -> int:
    last: dict[str, int] = {}
    left = best = 0
    for i, ch in enumerate(s):
        if last.get(ch, -1) >= left:
            left = last[ch] + 1
        last[ch] = i
        best = max(best, i - left + 1)
    return best
```

@@ Maximum Average Subarray I | Easy | Fixed window
Q: Return the maximum average of any contiguous subarray of length `k`.

A:
Seen in: JPMorgan-tagged list.

Approach: a fixed window with a running sum. Add the new element and subtract the one leaving.

```python
def find_max_average(nums: list[int], k: int) -> float:
    window = best = sum(nums[:k])
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]
        best = max(best, window)
    return best / k


assert find_max_average([1, 12, -5, -6, 50, 3], 4) == 12.75
```

@@ Minimum Size Subarray Sum | Medium | Variable window
Q: Given positive integers, return the minimal length of a contiguous subarray with sum ≥ `target`, or 0.

Example: `target = 7, [2,3,1,2,4,3]` → `2`
A:
Approach: grow the window on the right, then shrink it from the left while the sum still meets the target. This works because all values are positive, so the window sum is monotonic.

```python
def min_subarray_len(target: int, nums: list[int]) -> int:
    left = total = 0
    best = float("inf")
    for right, x in enumerate(nums):
        total += x
        while total >= target:
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float("inf") else int(best)
```

@@ Longest Repeating Character Replacement | Medium | Variable window
Q: You may replace at most `k` characters. Return the length of the longest substring of one repeated letter you can get.

Example: `"AABABBA", k = 1` → `4`
A:
Approach: a window is valid if `length - max_freq ≤ k`. `max_freq` never needs to decrease, because a smaller value can't produce a longer answer. When the window is invalid, slide it by one instead of shrinking it.

```python
from collections import Counter


def character_replacement(s: str, k: int) -> int:
    counts: Counter[str] = Counter()
    left = max_freq = best = 0
    for right, ch in enumerate(s):
        counts[ch] += 1
        max_freq = max(max_freq, counts[ch])
        if right - left + 1 - max_freq > k:
            counts[s[left]] -= 1
            left += 1
        best = max(best, right - left + 1)
    return best

assert character_replacement("", 3) == 0
```

@@ Permutation in String | Medium | Fixed window
Q: Return whether `s2` contains a permutation of `s1` as a substring.

Example: `"ab", "eidbaooo"` → `True`
A:
Approach: a fixed window of length `len(s1)`, compared against `s1`'s character counts as the window slides.

```python
from collections import Counter


def check_inclusion(s1: str, s2: str) -> bool:
    k = len(s1)
    if k > len(s2):
        return False
    need, window = Counter(s1), Counter(s2[:k])
    if window == need:
        return True
    for i in range(k, len(s2)):
        window[s2[i]] += 1
        out = s2[i - k]
        window[out] -= 1
        if window[out] == 0:
            del window[out]
        if window == need:
            return True
    return False


assert check_inclusion("ab", "eidbaooo")
assert not check_inclusion("ab", "eidboaoo")
assert not check_inclusion("abc", "ab")
```

Complexity: O(n·26) with Counter comparison. Tracking a `matches` counter makes it O(n).

Deleting zero counts keeps the equality check correct and fast.
F:
- Return all start indices (Find All Anagrams in a String).
- The O(n) matches-counter variant.

@@ Find All Anagrams in a String | Medium | Fixed window

```python
def find_anagrams(s: str, p: str) -> list[int]:

    return out
```

@@ Minimum Window Substring | Hard | Variable window
Q: Return the smallest substring of `s` that contains every character of `t`, including duplicates, or `""`.

Example: `s = "ADOBECODEBANC", t = "ABC"` → `"BANC"`
A:
Approach: expand `right` and track how many required characters are still `missing`. When it hits 0, shrink `left` past surplus characters (need < 0), record the window, then give up the left character and continue.

```python
from collections import Counter


def min_window(s: str, t: str) -> str:
    if not s or not t:
        return ""
    need = Counter(t)
    missing = len(t)
    left, best = 0, (0, -1)
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        if missing == 0:
            while need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if best[1] == -1 or right - left < best[1] - best[0]:
                best = (left, right)
            need[s[left]] += 1
            missing += 1
            left += 1
    return s[best[0]:best[1] + 1] if best[1] != -1 else ""


assert min_window("ADOBECODEBANC", "ABC") == "BANC"
assert min_window("a", "a") == "a"
assert min_window("a", "aa") == ""
assert min_window("aa", "aa") == "aa"
```

Complexity: O(|s| + |t|).

Talk through the invariant: `need[c] > 0` means the window still lacks c, and `need[c] < 0` means it has c to spare.
F:
- Smallest window containing all distinct characters of `s` itself.
- The same problem with a sequence order constraint (Minimum Window Subsequence, DP).

@@ Sliding Window Maximum | Hard | Monotonic deque
Q: Return the maximum of every window of size `k`.

Example: `[1,3,-1,-3,5,3,6,7], k = 3` → `[3,3,5,5,6,7]`
A:
Seen in: JPMorgan-tagged list.

Approach: a deque of indices whose values decrease from front to back. Pop smaller values from the back, since they can never be a maximum again, and pop the front when it leaves the window.

```python
from collections import deque


def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq: deque[int] = deque()
    out: list[int] = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out


assert max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3) == [3, 3, 5, 5, 6, 7]
assert max_sliding_window([1], 1) == [1]
assert max_sliding_window([9, 8, 7, 6], 2) == [9, 8, 7]
```

Complexity: O(n), since each index is pushed and popped at most once. A heap gives O(n log n).
F:
- Rolling max latency over the last 60 seconds of a metrics stream (time-based windows).
- Sliding window minimum and maximum together (two deques).

@@ Longest Substring with At Most K Distinct Characters | Medium | Variable window

A:
Approach: a window with a last-index map. When the window holds more than k distinct characters, evict the one whose last occurrence is leftmost. This moves `left` in one jump.

```python
def length_of_longest_substring_k_distinct(s: str, k: int) -> int:
    if k == 0:
        return 0
    last: dict[str, int] = {}
    left = best = 0
    for right, ch in enumerate(s):
        last.pop(ch, None)
        last[ch] = right
        if len(last) > k:
            _, idx = next(iter(last.items()))
            del last[s[idx]]
            left = idx + 1
        best = max(best, right - left + 1)
    return best
```

@@ Subarrays with K Different Integers | Hard | Window counting trick
Q: Count the subarrays with exactly `k` distinct integers.

Example: `[1,2,1,2,3], k = 2` → `7`
A:
Approach: exactly(k) = at_most(k) - at_most(k-1). In an at-most window ending at `right`, every start from `left` to `right` is valid, which gives `right - left + 1` subarrays.

```python
from collections import Counter


def subarrays_with_k_distinct(nums: list[int], k: int) -> int:
    def at_most(m: int) -> int:
        counts: Counter[int] = Counter()
        left = total = 0
        for right, x in enumerate(nums):
            counts[x] += 1
            while len(counts) > m:
                counts[nums[left]] -= 1
                if counts[nums[left]] == 0:
                    del counts[nums[left]]
                left += 1
            total += right - left + 1
        return total

    return at_most(k) - at_most(k - 1)


assert subarrays_with_k_distinct([1, 2, 1, 2, 3], 2) == 7
assert subarrays_with_k_distinct([1, 2, 1, 3, 4], 3) == 3
```

Complexity: O(n).
F:
- Why can't a single window count "exactly k" directly?

@@ Minimum Operations to Reduce X to Zero | Medium | Complement window

```python
def min_operations_reduce_x(nums: list[int], x: int) -> int:
    target = sum(nums) - x
    if target < 0:
        return -1
    if target == 0:
        return len(nums)
```

@@ Sliding Window Median | Hard | Order statistics
Q: Return the median of every window of size `k`.

Example: `[1,3,-1,-3,5,3,6,7], k = 3` → `[1,-1,-1,3,5,6]`
A:
Approach (interview-friendly): keep the window in a sorted list, updating it with `bisect.insort` and positional removal. This is O(n·k), which is fine for moderate k. The optimal approach uses two heaps with lazy deletion, or a sorted container, for O(n log k).

```python
from bisect import bisect_left, insort


def median_sliding_window(nums: list[int], k: int) -> list[float]:
    window = sorted(nums[:k])

    def median() -> float:
        if k % 2:
            return float(window[k // 2])
        return (window[k // 2 - 1] + window[k // 2]) / 2

    out = [median()]
    for i in range(k, len(nums)):
        window.pop(bisect_left(window, nums[i - k]))
        insort(window, nums[i])
        out.append(median())
    return out


assert median_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3) == [1.0, -1.0, -1.0, 3.0, 5.0, 6.0]
assert median_sliding_window([1, 2, 3, 4, 2, 3, 1, 4, 2], 3) == [2, 3, 3, 3, 2, 3, 2]
assert median_sliding_window([1, 4, 2, 3], 4) == [2.5]
```

Complexity: O(n·k) for list shifting, although `insort` is fast in practice because it is a C memmove.
F:
- Explain the two-heap lazy-deletion design.
- A rolling p50 or p99 latency over a stream (t-digest or HDR histogram in production).

@@ Repeated DNA Sequences | Medium | Rolling hash
Q: Return all 10-letter substrings that occur more than once in a DNA string.

Example: `"AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"` → `["AAAAACCCCC","CCCCCAAAAA"]`
A:
Approach: slide a length-10 window with seen and repeated sets. For very large inputs, encode each base in 2 bits so every window is a 20-bit integer rolling hash.

```python
def find_repeated_dna_sequences(s: str) -> list[str]:
    seen, repeated = set(), set()
    for i in range(len(s) - 9):
        chunk = s[i:i + 10]
        if chunk in seen:
            repeated.add(chunk)
        seen.add(chunk)
    return sorted(repeated)


def find_repeated_dna_bits(s: str) -> list[str]:
    code = {"A": 0, "C": 1, "G": 2, "T": 3}
    mask, h = (1 << 20) - 1, 0
    seen, repeated = set(), set()
    for i, ch in enumerate(s):
        h = ((h << 2) | code[ch]) & mask
        if i >= 9:
            if h in seen:
                repeated.add(s[i - 9:i + 1])
            seen.add(h)
    return sorted(repeated)
```

@@ Moving Average from Data Stream | Easy | Queue window
Q: Implement `MovingAverage(size)` with `next(val)` returning the average of the last `size` values.

Example: size 3: `next(1)=1.0, next(10)=5.5, next(3)=4.67, next(5)=6.0`
A:
Approach: a deque with `maxlen` plus a running sum, giving O(1) per call. This is the building block of rolling metrics such as average latency per model deployment.

```python
from collections import deque


class MovingAverage:
    def __init__(self, size: int) -> None:
        if size <= 0:
            raise ValueError("size must be positive")
        self._window: deque[float] = deque()
        self._size = size
        self._sum = 0.0

    def next(self, val: float) -> float:
        self._window.append(val)
        self._sum += val
        if len(self._window) > self._size:
            self._sum -= self._window.popleft()
        return self._sum / len(self._window)


m = MovingAverage(3)
assert m.next(1) == 1.0
assert m.next(10) == 5.5
assert abs(m.next(3) - 14 / 3) < 1e-9
assert m.next(5) == 6.0
```

Complexity: O(1) per call, O(size) space.

Note: a running float sum accumulates rounding error over millions of updates. Recompute periodically, or use integers or `math.fsum`.
F:
- A time-based window ("the last 60 seconds") with irregular arrivals.
- An exponentially weighted moving average, which needs O(1) memory.

@@ Subarray Sum Equals K | Medium | Prefix sum hashing

```python
from collections import Counter

        prefix += x
        total += seen[prefix - k]
        seen[prefix] += 1
    return total
```

@@ Subarray Sums Divisible by K | Medium | Prefix sum modulo

```python
    return total
```

@@ Range Sum Query 2D - Immutable | Medium | 2-D prefix sums
Q: Design `NumMatrix(matrix)` with `sum_region(r1, c1, r2, c2)` (inclusive corners) in O(1).
A:
Approach: `P[r][c]` is the sum of the rectangle from (0,0) to (r-1,c-1), with one padding row and column. Answer by inclusion-exclusion: `P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]`.

```python
class NumMatrix:
    def __init__(self, matrix: list[list[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0]) if matrix else 0
        self._p = [[0] * (cols + 1) for _ in range(rows + 1)]
        for r in range(rows):
            for c in range(cols):
                self._p[r + 1][c + 1] = (matrix[r][c] + self._p[r][c + 1]
                                         + self._p[r + 1][c] - self._p[r][c])

    def sum_region(self, r1: int, c1: int, r2: int, c2: int) -> int:
        p = self._p
        return p[r2 + 1][c2 + 1] - p[r1][c2 + 1] - p[r2 + 1][c1] + p[r1][c1]


nm = NumMatrix([[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]])
assert nm.sum_region(2, 1, 4, 3) == 8
assert nm.sum_region(1, 1, 2, 2) == 11
assert nm.sum_region(1, 2, 2, 4) == 12
```

Complexity: O(m·n) to build, O(1) per query.
F:
- Mutable version (2-D Fenwick tree).
- Maximum-sum rectangle no larger than k.

@@ Car Pooling | Medium | Sweep line
Q: `trips[i] = [passengers, from, to]`. A car with `capacity` seats drives east only. Can it complete every trip? Passengers get off at `to` before others board there.
A:
Approach: turn each trip into events `(from, +p)` and `(to, -p)`. Sort them and keep a running load. Because drop-offs have negative deltas, a tuple sort puts them before pick-ups at the same location, which matches the rule.

```python
def car_pooling(trips: list[list[int]], capacity: int) -> bool:
    events = []
    for p, start, end in trips:
        events.append((start, p))
        events.append((end, -p))
    load = 0
    for _, delta in sorted(events):
        load += delta
        if load > capacity:
            return False
    return True


assert not car_pooling([[2, 1, 5], [3, 3, 7]], 4)
assert car_pooling([[2, 1, 5], [3, 3, 7]], 5)
assert car_pooling([[2, 1, 5], [3, 5, 7]], 3)
```

Complexity: O(n log n). With small location bounds (≤ 1000), a difference array gives O(n + L).
F:
- The difference-array version.
- Capacity planning: peak concurrent LLM requests per deployment from request logs.

@@ Shortest Subarray with Sum at Least K | Hard | Monotonic deque on prefix sums
Q: Return the length of the shortest non-empty subarray with sum ≥ `k`. Values may be negative. Return -1 if none exists.

Example: `[2,-1,2], k = 3` → `3`
A:
Approach: over the prefix sums, keep a deque of indices with increasing prefix values.
- While the current prefix minus the front's prefix is ≥ k, record the length and pop the front, since a later end can't make it shorter.
- Pop from the back any prefix ≥ the current one, because the current index is a better start (smaller value, later position).

```python
from collections import deque
from itertools import accumulate


def shortest_subarray(nums: list[int], k: int) -> int:
    prefix = [0, *accumulate(nums)]
    dq: deque[int] = deque()
    best = len(nums) + 1
    for i, p in enumerate(prefix):
        while dq and p - prefix[dq[0]] >= k:
            best = min(best, i - dq.popleft())
        while dq and prefix[dq[-1]] >= p:
            dq.pop()
        dq.append(i)
    return best if best <= len(nums) else -1


assert shortest_subarray([1], 1) == 1
assert shortest_subarray([1, 2], 4) == -1
assert shortest_subarray([2, -1, 2], 3) == 3
assert shortest_subarray([84, -37, 32, 40, 95], 167) == 3
```

Complexity: O(n).
F:
- Why does the positive-only sliding window fail here?

@@ Product of the Last K Numbers | Medium | Prefix products

Approach: keep prefix products and reset them on a zero. If k reaches back past the last zero, the product is 0.

```python
class ProductOfNumbers:
    def __init__(self) -> None:
        self._prefix = [1]

    def add(self, num: int) -> None:
        if num == 0:
            self._prefix = [1]
        else:
            self._prefix.append(self._prefix[-1] * num)

    def get_product(self, k: int) -> int:
        if k >= len(self._prefix):
            return 0
        return self._prefix[-1] // self._prefix[-1 - k]

assert p.get_product(3) == 40
assert p.get_product(4) == 0
```

@@ Plates Between Candles | Medium | Prefix sums with nearest markers
Q: `s` consists of `*` (plates) and `|` (candles). For each query `[l, r]`, count the plates that lie between two candles inside `s[l..r]`.

Example: `"**|**|***|", [[2,5],[5,9]]` → `[2,3]`
A:
Approach: precompute the plate prefix counts, the nearest candle at or after each index, and the nearest candle at or before each index. Each query is then O(1).

```python
def plates_between_candles(s: str, queries: list[list[int]]) -> list[int]:
    n = len(s)
    plates = [0] * (n + 1)
    for i, ch in enumerate(s):
        plates[i + 1] = plates[i] + (ch == "*")
    prev_candle, last = [-1] * n, -1
    for i in range(n):
        if s[i] == "|":
            last = i
        prev_candle[i] = last
    next_candle, last = [n] * n, n
    for i in range(n - 1, -1, -1):
        if s[i] == "|":
            last = i
        next_candle[i] = last
    out = []
    for l, r in queries:
        a, b = next_candle[l], prev_candle[r]
        out.append(plates[b] - plates[a] if a < b else 0)
    return out


assert plates_between_candles("**|**|***|", [[2, 5], [5, 9]]) == [2, 3]
assert plates_between_candles("***|**|*****|**||**|*",
```

- Solve with binary search over the candle positions instead of the two arrays.

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    merged: list[list[int]] = []
    for start, end in sorted(intervals):
        if merged and start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

assert merge_intervals([[1, 4], [4, 5]]) == [[1, 5]]
assert merge_intervals([[1, 4], [2, 3]]) == [[1, 4]]
assert merge_intervals([]) == []
```

Complexity: O(n log n) time, O(n) output.

Watch for: `max` on the end (contained intervals), and whether touching intervals count as overlapping (clarify with the interviewer).
F:
- Intervals arrive as a stream (Data Stream as Disjoint Intervals).
- Merge per-user login sessions from logs.

@@ Insert Interval | Medium | Intervals
Q: Insert `new` into a sorted, non-overlapping interval list, merging where necessary.

Example: `[[1,2],[3,5],[6,7],[8,10],[12,16]], [4,8]` → `[[1,2],[3,10],[12,16]]`
A:
Approach: three phases in a single pass: copy the intervals that end before `new`, merge everything that overlaps it, then copy the rest.

```python
def insert_interval(intervals: list[list[int]], new: list[int]) -> list[list[int]]:
    out, i, n = [], 0, len(intervals)
    start, end = new
    while i < n and intervals[i][1] < start:
        out.append(intervals[i])
        i += 1
    while i < n and intervals[i][0] <= end:
        start = min(start, intervals[i][0])
        end = max(end, intervals[i][1])
        i += 1
    out.append([start, end])
    out.extend(intervals[i:])
    return out


assert insert_interval([[1, 3], [6, 9]], [2, 5]) == [[1, 5], [6, 9]]
assert insert_interval([[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]], [4, 8]) == [[1, 2], [3, 10], [12, 16]]
assert insert_interval([], [5, 7]) == [[5, 7]]
assert insert_interval([[1, 5]], [6, 8]) == [[1, 5], [6, 8]]
```

Complexity: O(n). Binary search can find the boundaries, but copying is still O(n).
F:
- Remove an interval from the set.

@@ Non-overlapping Intervals | Medium | Greedy by end

```python
def erase_overlap_intervals(intervals: list[list[int]]) -> int:
```

@@ Meeting Rooms II | Medium | Heap or sweep
Q: Return the minimum number of rooms needed to hold all the meetings (half-open intervals).

Example: `[[0,30],[5,10],[15,20]]` → `2`
A:
Seen in: JPMorgan-tagged list (high frequency). It also shows up as "Maximum Number of Overlapping Intervals" in reported coding rounds.

Approach: sort by start and keep a min-heap of end times. Reuse the room that frees up first if it's free by the new start. The heap size at the end is the answer.

```python
import heapq


def min_meeting_rooms(intervals: list[list[int]]) -> int:
    ends: list[int] = []
    for start, end in sorted(intervals):
        if ends and ends[0] <= start:
            heapq.heapreplace(ends, end)
        else:
            heapq.heappush(ends, end)
    return len(ends)


def min_meeting_rooms_sweep(intervals: list[list[int]]) -> int:
    starts = sorted(s for s, _ in intervals)
    ends = sorted(e for _, e in intervals)
    rooms = best = j = 0
    for s in starts:
        while ends[j] <= s:
            j += 1
            rooms -= 1
        rooms += 1
        best = max(best, rooms)
    return best


for f in (min_meeting_rooms, min_meeting_rooms_sweep):

    assert f([[1, 5], [5, 10]]) == 1
    assert f([[1, 10], [2, 7], [3, 19], [8, 12], [10, 20], [11, 30]]) == 4
```

```python
def employee_free_time(schedule: list[list[list[int]]]) -> list[list[int]]:
```

@@ Two Best Non-Overlapping Events | Medium | Sort, suffix max, binary search
Q: `events[i] = [start, end, value]` with inclusive times. Choose at most two non-overlapping events (the second must start after the first ends) to maximise the total value.

Example: `[[1,3,2],[4,5,2],[2,4,3]]` → `4`
A:
Seen in: JPMorgan-tagged list.

Approach: sort by start and build a suffix maximum of values. For each event, binary-search the first event whose start is greater than its end, and combine the two values.

```python
from bisect import bisect_right


def max_two_events(events: list[list[int]]) -> int:
    ev = sorted(events)
    starts = [e[0] for e in ev]
    suffix = [0] * (len(ev) + 1)
    for i in range(len(ev) - 1, -1, -1):
        suffix[i] = max(suffix[i + 1], ev[i][2])
    best = 0
    for _, end, value in ev:
        j = bisect_right(starts, end)
        best = max(best, value + suffix[j])
    return best


assert max_two_events([[1, 3, 2], [4, 5, 2], [2, 4, 3]]) == 4
assert max_two_events([[1, 3, 2], [4, 5, 2], [1, 5, 5]]) == 5
assert max_two_events([[1, 5, 3], [1, 5, 1], [6, 6, 5]]) == 8
```

Complexity: O(n log n).
F:
- At most k events (DP over the sorted events with binary search, O(nk log n)).

@@ Maximum Concurrent Sessions | Medium | Sweep line

@@ My Calendar I | Medium | Sorted intervals with bisect

Approach: keep bookings sorted. Binary-search the insertion point and check only the two neighbours.

```python
from bisect import bisect_left


class MyCalendar:
    def __init__(self) -> None:
        self._bookings: list[tuple[int, int]] = []

    def book(self, start: int, end: int) -> bool:
        b = self._bookings
        i = bisect_left(b, (start, end))
        if i > 0 and b[i - 1][1] > start:
            return False
        if i < len(b) and b[i][0] < end:
            return False
        b.insert(i, (start, end))
        return True

assert cal.book(5, 10) is True
assert cal.book(9, 11) is False
```

@@ My Calendar II | Medium | Overlap tracking

A:
Approach: store the single bookings and the double-booked overlaps separately. A new booking fails if it intersects any overlap. Otherwise, record its intersections with the single bookings as new overlaps.

```python
class MyCalendarTwo:
    def __init__(self) -> None:
        self._bookings: list[tuple[int, int]] = []
        self._overlaps: list[tuple[int, int]] = []

    def book(self, start: int, end: int) -> bool:
        if any(start < b and a < end for a, b in self._overlaps):
            return False
        for a, b in self._bookings:
            if start < b and a < end:
                self._overlaps.append((max(a, start), min(b, end)))
        self._bookings.append((start, end))
        return True
```

@@ Data Stream as Disjoint Intervals | Hard | Sorted intervals
Q: Design `add_num(v)` and `get_intervals()`, which returns the numbers seen so far as a sorted list of disjoint intervals.
A:
Approach: keep a sorted list of `[start, end]`. On insertion, binary-search the position, skip if `v` is already covered, and otherwise merge with the left neighbour, the right neighbour, both, or neither.

```python
from bisect import bisect_left


class SummaryRanges:
    def __init__(self) -> None:
        self._iv: list[list[int]] = []

    def add_num(self, v: int) -> None:
        iv = self._iv
        i = bisect_left(iv, [v, v])
        if i < len(iv) and iv[i][0] == v:
            return
        if i > 0 and iv[i - 1][1] >= v:
            return
        joins_left = i > 0 and iv[i - 1][1] == v - 1
        joins_right = i < len(iv) and iv[i][0] == v + 1
        if joins_left and joins_right:
            iv[i - 1][1] = iv[i][1]
            iv.pop(i)
        elif joins_left:
            iv[i - 1][1] = v
        elif joins_right:
            iv[i][0] = v
        else:
            iv.insert(i, [v, v])

    def get_intervals(self) -> list[list[int]]:
        return [list(x) for x in self._iv]


sr = SummaryRanges()
snapshots = []
for v in (1, 3, 7, 2, 6, 2):
    sr.add_num(v)
    snapshots.append(sr.get_intervals())
assert snapshots[0] == [[1, 1]]
assert snapshots[3] == [[1, 3], [7, 7]]
assert snapshots[4] == [[1, 3], [6, 7]]
assert snapshots[5] == [[1, 3], [6, 7]]
```

Complexity: O(log n) search plus O(n) list insertion. A balanced tree (`SortedList`) gives O(log n).

- Many adds and few gets? (Store a set and build the intervals lazily.)

@@ Maximum Number of Events That Can Be Attended | Medium | Greedy with heap
Q: `events[i] = [start, end]` (inclusive days). You can attend one event per day. Return the maximum number of events you can attend.

Example: `[[1,2],[2,3],[3,4],[1,2]]` → `4`
A:
Approach: sweep the days. Push the end days of events that have started into a min-heap, then attend the one that ends soonest. Drop expired events.

```python
import heapq


def max_events(events: list[list[int]]) -> int:
    ev = sorted(events)
    heap: list[int] = []
    i, day, attended, n = 0, 0, 0, len(ev)
    while i < n or heap:
        if not heap:
            day = max(day, ev[i][0])
        while i < n and ev[i][0] <= day:
            heapq.heappush(heap, ev[i][1])
            i += 1
        heapq.heappop(heap)
        attended += 1
        day += 1
        while heap and heap[0] < day:
            heapq.heappop(heap)
    return attended


assert max_events([[1, 2], [2, 3], [3, 4]]) == 3
assert max_events([[1, 2], [2, 3], [3, 4], [1, 2]]) == 4
assert max_events([[1, 4], [4, 4], [2, 2], [3, 4], [1, 1]]) == 4
```

Complexity: O(n log n).
F:
- Why is "earliest deadline first" optimal here?

@@ Sort an Array | Medium | Merge sort
Q: Sort an integer array in O(n log n) without built-in sort functions.
A:
Seen in: JPMorgan-tagged list.

Approach: merge sort is stable, guarantees O(n log n) and is easy to get right. Quicksort is in-place, but its worst case is O(n²) unless the pivot is randomised.

```python
import random


def merge_sort(nums: list[int]) -> list[int]:
    if len(nums) <= 1:
        return list(nums)
    mid = len(nums) // 2
    left, right = merge_sort(nums[:mid]), merge_sort(nums[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i])
            i += 1
        else:
            out.append(right[j])
            j += 1
    out.extend(left[i:])
    out.extend(right[j:])
    return out


rng = random.Random(0)
for _ in range(100):
    data = [rng.randint(-50, 50) for _ in range(rng.randint(0, 40))]
    assert merge_sort(data) == sorted(data)
```

Complexity: O(n log n) time, O(n) space.

`<=` in the merge keeps it stable. Python's `sorted` is Timsort, which is stable and adaptive (O(n) on nearly sorted input).
F:
- Why is stability important when sorting records by several keys?
- Implement iterative bottom-up merge sort.

@@ Kth Largest Element in an Array | Medium | Quickselect
Q: Return the k-th largest element without fully sorting.

Example: `[3,2,1,5,6,4], k = 2` → `5`
A:
Seen in: JPMorgan-tagged list.

Approach: quickselect with a random pivot and a 3-way partition, which also handles duplicates. The expected cost is O(n). The alternative is a size-k min-heap in O(n log k), which is predictable and works on streams.

```python
import heapq
import random


def find_kth_largest(nums: list[int], k: int, rng: random.Random = random.Random(0)) -> int:
    a = list(nums)
    target = len(a) - k
    lo, hi = 0, len(a) - 1
    while True:
        pivot = a[rng.randint(lo, hi)]
        lt, i, gt = lo, lo, hi
        while i <= gt:
            if a[i] < pivot:
                a[lt], a[i] = a[i], a[lt]
                lt += 1
                i += 1
            elif a[i] > pivot:
                a[i], a[gt] = a[gt], a[i]
                gt -= 1
            else:
                i += 1
        if target < lt:
            hi = lt - 1
        elif target > gt:
            lo = gt + 1
        else:
            return pivot


def find_kth_largest_heap(nums: list[int], k: int) -> int:
    return heapq.nlargest(k, nums)[-1]


for f in (find_kth_largest, find_kth_largest_heap):
    assert f([3, 2, 1, 5, 6, 4], 2) == 5
    assert f([3, 2, 3, 1, 2, 4, 5, 5, 6], 4) == 4
    assert f([1], 1) == 1
```

Complexity: quickselect is O(n) expected and O(n²) worst case. Median-of-medians guarantees O(n).
F:
- Which one would you use on a stream? (The heap.)
- Top-k tokens by log-probability. Which approach, and why?

@@ Largest Number | Medium | Custom comparator
Q: Arrange non-negative integers so they form the largest possible number. Return it as a string.

Example: `[3,30,34,5,9]` → `"9534330"`
A:
Approach: `a` should come before `b` if `a+b > b+a` as strings. Sort with `functools.cmp_to_key`. If the result starts with `"0"`, all the values are zero.

```python
from functools import cmp_to_key


def largest_number(nums: list[int]) -> str:
    strs = [str(n) for n in nums]
    strs.sort(key=cmp_to_key(lambda a, b: (b + a > a + b) - (a + b > b + a)))
    result = "".join(strs)
    return "0" if result[0] == "0" else result


assert largest_number([10, 2]) == "210"
assert largest_number([3, 30, 34, 5, 9]) == "9534330"
```

@@ Sort Array By Parity | Easy | Two pointers

```python
def sort_array_by_parity(nums: list[int]) -> list[int]:

            i += 1

        else:

    return nums
```

@@ Minimum Platforms Required | Medium | Sweep with two sorted arrays
Q: Given the arrival and departure times of trains at a station, return the minimum number of platforms so no train waits. A train arriving at the same minute another departs needs a separate platform.

Example: `arr=[900,940,950,1100,1500,1800], dep=[910,1200,1120,1130,1900,2000]` → `3`
A:
Approach: sort both lists and merge them with two pointers. An arrival at or before the next departure needs a new platform (inclusive semantics).

```python
def min_platforms(arrivals: list[int], departures: list[int]) -> int:
    a, d = sorted(arrivals), sorted(departures)
    i = j = platforms = best = 0
    while i < len(a):
        if a[i] <= d[j]:
            platforms += 1
            best = max(best, platforms)
            i += 1
        else:
            platforms -= 1
            j += 1
    return best


assert min_platforms([900, 940, 950, 1100, 1500, 1800], [910, 1200, 1120, 1130, 1900, 2000]) == 3
assert min_platforms([900, 1100, 1235], [1000, 1200, 1240]) == 1
assert min_platforms([100, 100], [200, 200]) == 2
```

Complexity: O(n log n).
F:
- How does this differ from Meeting Rooms II? (Inclusive versus half-open semantics.)

@@ H-Index | Medium | Counting sort
Q: The h-index is the largest h such that the researcher has at least h papers with at least h citations each. Compute it.

Example: `[3,0,6,1,5]` → `3`
A:
Approach: bucket by citation count, capped at n, then walk down from n accumulating papers until the count reaches h. This is O(n) and avoids an O(n log n) sort.

```python
def h_index(citations: list[int]) -> int:
    n = len(citations)
    buckets = [0] * (n + 1)
    for c in citations:
        buckets[min(c, n)] += 1
    total = 0
    for h in range(n, -1, -1):
        total += buckets[h]
        if total >= h:
            return h
    return 0


assert h_index([3, 0, 6, 1, 5]) == 3
assert h_index([1, 3, 1]) == 1
assert h_index([0]) == 0
assert h_index([100]) == 1
```

Complexity: O(n) time and space.
F:
- H-Index II: the input is sorted, so binary search in O(log n).

@@ Count Inversions in an Array | Hard | Merge sort
Q: Count the pairs `i < j` with `a[i] > a[j]`.

Example: `[2,4,1,3,5]` → `3`
A:
Approach: augment merge sort. When an element from the right half is placed before the remaining left-half elements, it forms an inversion with each of them.

```python
import random


def count_inversions(a: list[int]) -> int:
    def sort(xs: list[int]) -> tuple[list[int], int]:
        if len(xs) <= 1:
            return xs, 0
        mid = len(xs) // 2
        left, x = sort(xs[:mid])
        right, y = sort(xs[mid:])
        merged, i, j, inv = [], 0, 0, x + y
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i])
                i += 1
            else:
                merged.append(right[j])
                inv += len(left) - i
                j += 1
        merged += left[i:] + right[j:]
        return merged, inv

    return sort(list(a))[1]


assert count_inversions([2, 4, 1, 3, 5]) == 3
assert count_inversions([5, 4, 3, 2, 1]) == 10
assert count_inversions([]) == 0
rng = random.Random(3)
for _ in range(50):
    xs = [rng.randint(0, 20) for _ in range(30)]
    brute = sum(xs[i] > xs[j] for i in range(len(xs)) for j in range(i + 1, len(xs)))
    assert count_inversions(xs) == brute
```

Complexity: O(n log n). The alternative is a Fenwick tree over compressed values.
F:
- Kendall tau distance between two rankings, for example when comparing a reranker's ordering with human labels.

@@ Wiggle Sort | Medium | Greedy swaps
Q: Reorder in place so that `nums[0] <= nums[1] >= nums[2] <= nums[3] ...`.
A:
Approach: one pass. At an odd index you need `nums[i-1] <= nums[i]`, and at an even index `nums[i-1] >= nums[i]`. When the condition fails, swapping the neighbours fixes it without breaking the previous pair.

```python
def wiggle_sort(nums: list[int]) -> None:
    for i in range(1, len(nums)):
        if (i % 2 == 1) != (nums[i - 1] <= nums[i]):
            nums[i - 1], nums[i] = nums[i], nums[i - 1]


def is_wiggle(a: list[int]) -> bool:
    return all((a[i - 1] <= a[i]) if i % 2 else (a[i - 1] >= a[i]) for i in range(1, len(a)))


for case in ([3, 5, 2, 1, 6, 4], [1, 2, 3, 4, 5], [5, 4, 3, 2, 1], [1, 1, 1], []):
    wiggle_sort(case)
    assert is_wiggle(case)
```

Complexity: O(n) time, O(1) space.
F:
- Wiggle Sort II with strict inequalities (median plus 3-way partition with virtual indexing).

@@ Pancake Sorting | Medium | Constructive
Q: A flip reverses the prefix `arr[:k]`. Return a sequence of flips that sorts the permutation `arr`, using at most 10n flips.
A:
Approach: for size from n down to 2, flip the maximum to the front, then flip it into its final place. This uses at most 2n flips.

```python
def pancake_sort(arr: list[int]) -> list[int]:
    a, flips = list(arr), []
    for size in range(len(a), 1, -1):
        i = a.index(size)
        if i == size - 1:
            continue
        if i != 0:
            flips.append(i + 1)
            a[:i + 1] = reversed(a[:i + 1])
        flips.append(size)
        a[:size] = reversed(a[:size])
    return flips


def apply(arr: list[int], flips: list[int]) -> list[int]:
    a = list(arr)
    for k in flips:
        a[:k] = reversed(a[:k])
    return a


for case in ([3, 2, 4, 1], [1, 2, 3], [2, 1], [5, 1, 4, 2, 3]):
    flips = pancake_sort(case)
    assert apply(case, flips) == sorted(case) and len(flips) <= 2 * len(case)
```

Complexity: O(n²).
F:
- The minimum number of flips is NP-hard. Why is 2n still acceptable here?

```python
from decimal import Decimal

    out.sort(key=lambda t: t["amount"], reverse=True)
    out.sort(key=lambda t: (t["date"] is None, t["date"] or ""))
    return out
```

@@ Maximum Gap | Hard | Bucket sort
Q: Return the maximum difference between successive elements in sorted order, in linear time.

Example: `[3,6,9,1]` → `3`
A:
Approach: pigeonhole. With n numbers spanning `hi - lo`, the maximum gap is at least `ceil((hi-lo)/(n-1))`. Use buckets of that width (at least 1). Then the maximum gap never falls inside a bucket, so compare each bucket's minimum with the previous non-empty bucket's maximum.

```python
import random


def maximum_gap(nums: list[int]) -> int:
    if len(nums) < 2:
        return 0
    lo, hi = min(nums), max(nums)
    if lo == hi:
        return 0
    n = len(nums)
    size = max(1, (hi - lo) // (n - 1))
    count = (hi - lo) // size + 1
    bmin = [None] * count
    bmax = [None] * count
    for x in nums:
        b = (x - lo) // size
        bmin[b] = x if bmin[b] is None else min(bmin[b], x)
        bmax[b] = x if bmax[b] is None else max(bmax[b], x)
    best, prev = 0, lo
    for b in range(count):
        if bmin[b] is None:
            continue
        best = max(best, bmin[b] - prev)
        prev = bmax[b]
    return best


assert maximum_gap([3, 6, 9, 1]) == 3
assert maximum_gap([10]) == 0
assert maximum_gap([1, 10_000_000]) == 9_999_999
rng = random.Random(5)
for _ in range(100):
    xs = [rng.randint(0, 1000) for _ in range(rng.randint(2, 30))]
    s = sorted(xs)
    assert maximum_gap(xs) == max(b - a for a, b in zip(s, s[1:]))
```

Complexity: O(n) time and space. Radix sort is another O(n·d) option.
F:
- Why can't the maximum gap lie inside a single bucket?

@@ Advantage Shuffle | Medium | Greedy matching
Q: Permute `nums1` to maximise the number of indices where `nums1[i] > nums2[i]`.

Example: `[2,7,11,15], [1,10,4,11]` → `[2,11,7,15]`
A:
Approach: the "Tian Ji horse race" greedy. Process `nums2` from largest to smallest. If our largest remaining value beats it, use it. Otherwise sacrifice our smallest.

```python
def advantage_count(nums1: list[int], nums2: list[int]) -> list[int]:
    a = sorted(nums1)
    lo, hi = 0, len(a) - 1
    out = [0] * len(nums2)
    for i in sorted(range(len(nums2)), key=lambda i: nums2[i], reverse=True):
        if a[hi] > nums2[i]:
            out[i] = a[hi]
            hi -= 1
        else:
            out[i] = a[lo]
            lo += 1
    return out


assert advantage_count([2, 7, 11, 15], [1, 10, 4, 11]) == [2, 11, 7, 15]
assert advantage_count([12, 24, 8, 32], [13, 25, 32, 11]) == [24, 32, 8, 12]
```

Complexity: O(n log n).
F:
- Prove that sacrificing the smallest is never worse.

@@ Queue Reconstruction by Height | Medium | Greedy insertion
Q: `people[i] = [h, k]`, where k is the number of people in front who are at least h tall. Reconstruct the queue.

```python
def reconstruct_queue(people: list[list[int]]) -> list[list[int]]:

        out.insert(k, [h, k])
    return out
```

@@ Reconcile Two Sorted Ledgers | Medium | Two-pointer merge
Q: You have a bank statement and an internal ledger. Each is a list of `(date, ref, amount_cents)` sorted by `(date, ref)`, and `(date, ref)` is unique within each list. Produce a reconciliation report: matched entries, amount mismatches, entries only in the bank statement, and entries only in the ledger.
A:
Why it matters here: reconciliation is core Corporate Technology work (Finance, Treasury). The two-pointer merge is the same step a sort-merge join performs.

Approach: walk both lists with two pointers, comparing keys. Equal keys are either matched or a mismatch. Otherwise, advance the side with the smaller key and report it as unmatched. Amounts are integers in minor units (cents) to avoid floating-point errors.

```python
from dataclasses import dataclass, field


@dataclass
class Report:
    matched: list[tuple] = field(default_factory=list)
    mismatched: list[tuple] = field(default_factory=list)
    only_bank: list[tuple] = field(default_factory=list)
    only_ledger: list[tuple] = field(default_factory=list)


def reconcile(bank: list[tuple[str, str, int]], ledger: list[tuple[str, str, int]]) -> Report:
    for name, rows in (("bank", bank), ("ledger", ledger)):
        keys = [r[:2] for r in rows]
        if keys != sorted(keys) or len(set(keys)) != len(keys):
            raise ValueError(f"{name} must be sorted by (date, ref) with unique keys")
    rep, i, j = Report(), 0, 0
    while i < len(bank) and j < len(ledger):
        kb, kl = bank[i][:2], ledger[j][:2]
        if kb == kl:
            if bank[i][2] == ledger[j][2]:
                rep.matched.append(bank[i])
            else:
                rep.mismatched.append((*kb, bank[i][2], ledger[j][2]))
            i, j = i + 1, j + 1
        elif kb < kl:
            rep.only_bank.append(bank[i])
            i += 1
        else:
            rep.only_ledger.append(ledger[j])
            j += 1
    rep.only_bank.extend(bank[i:])
    rep.only_ledger.extend(ledger[j:])
    return rep


bank = [("2026-09-01", "A1", 10_000), ("2026-09-01", "A2", 2_500), ("2026-09-02", "B7", 990)]
ledger = [("2026-09-01", "A1", 10_000), ("2026-09-01", "A2", 2_050), ("2026-09-02", "C3", 400)]
r = reconcile(bank, ledger)
assert r.matched == [("2026-09-01", "A1", 10_000)]
assert r.mismatched == [("2026-09-01", "A2", 2_500, 2_050)]
assert r.only_bank == [("2026-09-02", "B7", 990)]
assert r.only_ledger == [("2026-09-02", "C3", 400)]
```

Complexity: O(n + m) time after O(n log n) validation (or O(n) if you trust the sort order).

Talking points: validate your inputs (fail loudly), use integer minor units, and make the report auditable.
F:
- Keys aren't unique and duplicates must be matched greedily by amount.
- Fuzzy matching when references are missing (date ± 1 day and exact amount) and how you'd avoid double matches.
- Scale to 100 million rows per day (push it into SQL as a FULL OUTER JOIN, or run it as a Spark job).
